# Dark-surface palette notes

`eclipse` (8), `afterglow` (12), and `deepfield` (20) are nested.
Earlier colors and names are preserved when moving up a size.
These additions do not change any original or Galaxy 40 colors.

Colors are art-directed for luminous but softer-than-neon appearances on
`#081126`, `#101827`, or black. Each solid swatch has WCAG-formula
relative luminance contrast of at least 5.2:1 against those backgrounds,
tested in `tests/test-dark-surfaces.R`. Approximate minimum pairwise
CIEDE2000 for the 20-color set is 13.8 in normal-vision screening.

This is not an accessibility certification. Small markers, transparency,
color-vision deficiency, text, lines, and projectors require testing in context.
Use categorical values only, and add labels to dense figures.
